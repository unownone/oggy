# Oggy architecture docs

This folder is the design-doc convention for Oggy.

- Specs here are **normative**: types and runtime hooks in `src/` must follow them.
- When behavior and a spec disagree, fix the code or amend the spec in the same change.
- Prefer a sharp spec + typed contracts over an incomplete feature rewrite.
